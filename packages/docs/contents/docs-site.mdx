# Docs Site

The documentation site is a Vite, React, and MDX static site in `packages/docs`. It documents this customized Jacky's Photography repository rather than upstream Afilmory in general, so examples should match the current workspace, deployment workflow, and local `builder.config.ts`.

## Content Structure

Documentation pages live in `packages/docs/contents/`:

- `index.mdx` introduces the project, photo pipeline, and deployment flow.
- `photo-metadata/index.mdx` documents manual descriptions, tag curation, manifest merge behavior, and photo SEO output.
- `storage/index.mdx` documents supported builder storage providers.
- `performance/index.mdx` records image loading, manifest, and chunk-splitting decisions.
- `deployment/*.mdx` contains platform-specific deployment notes.
- `docs-site.mdx` explains how to maintain this documentation site.

Route generation follows the file system:

- `contents/index.mdx` becomes `/`.
- `contents/storage/index.mdx` becomes `/storage`.
- `contents/photo-metadata/index.mdx` becomes `/photo-metadata`.
- `contents/deployment/github-pages.mdx` becomes `/deployment/github-pages`.

The route generator writes `src/routes.ts` and `src/routes.json`; treat both as generated files.

## Commands

From the repository root:

```bash
pnpm docs:dev
pnpm docs:build
pnpm docs:preview
pnpm create:doc
```

From `packages/docs/` directly:

```bash
pnpm dev
pnpm build
pnpm preview
pnpm create:doc
```

`pnpm docs:build` runs the package build pipeline: TypeScript and Vite client build, SSR/static rendering, and final output processing through `packages/docs/scripts/build.ts`.

## Writing Pages

Every page should include frontmatter:

```yaml
---
title: Page Title
description: Short page description.
createdAt: 2026-04-29T00:00:00+08:00
lastModified: 2026-04-29T00:00:00+08:00
---
```

Update `lastModified` whenever a content page changes. The repository hook runs `pnpm update:lastmodified` for staged Markdown and MDX files, and you can also run it manually with file paths when needed.

Use `pnpm create:doc` for new pages when you want the scaffolded frontmatter and route placement prompts.

## Style Notes

- Keep examples aligned with Node.js 24, pnpm 10.19.0, React 19, Vite, and the current workspace packages.
- Document the static SPA workflow: `pnpm build` produces `apps/web/dist/`, and GitHub Actions mirrors that output into root `web/`.
- Keep photo metadata docs aligned with `photo-descriptions.json`, `scripts/sync-photo-descriptions.ts`, and `plugins/builder/photo-descriptions.ts`.
- When describing profile links, use the current `siteConfig.social` fields, including `instagram`.
- Do not describe `photos/` as reusable sample assets; those files are personal copyrighted works.
- Prefer short, operational sections over generic product copy.
- When changing `packages/docs/contents/deployment/*`, verify the commands against `.github/workflows/deploy.yml` and root `package.json`.

## Verification

Before publishing documentation changes, run:

```bash
pnpm docs:build
```

For content-only edits, this catches route generation, MDX syntax, and static rendering issues.
